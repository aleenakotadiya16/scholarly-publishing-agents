# Pre-Submission Self-Review Checklist

## Purpose

A structured self-review to catch common issues before formal submission. This checklist should be completed by the author with AI assistance, addressing every item before moving to reference validation.

---

## Content Quality

- [ ] **Research question** clearly stated in the Introduction
- [ ] **Hypothesis or objectives** explicitly defined
- [ ] **Methods** sufficiently detailed for replication
- [ ] **Results** presented completely, including negative findings
- [ ] **Discussion** addresses all results, including unexpected findings
- [ ] **Limitations** honestly and comprehensively described
- [ ] **Conclusions** supported by the data (no overclaiming)
- [ ] **No data fabrication or falsification** — all data is real and traceable
- [ ] **No selective reporting** — all pre-specified outcomes reported

## Statistical Reporting

- [ ] **Statistical tests** named and justified
- [ ] **Significance level** (alpha) stated
- [ ] **Effect sizes** reported with confidence intervals
- [ ] **Sample sizes** reported for all analyses
- [ ] **Missing data** handling described
- [ ] **Multiple comparisons** adjustment described if applicable
- [ ] **Assumptions** checked and reported (normality, homogeneity, etc.)
- [ ] **Software** used for analysis identified with version number
- [ ] **P-values** reported to appropriate precision (not just "< 0.05")

## References

- [ ] **All in-text citations** have corresponding entries in the reference list
- [ ] **All reference list entries** are cited in the text
- [ ] **Reference formatting** matches target journal style
- [ ] **No orphan references** (cited but not listed, or listed but not cited)
- [ ] **DOIs** included where available
- [ ] **Retracted papers** not cited (check Retraction Watch)
- [ ] **Citation verification** completed (see `reference-validation.md`)

## Ethical Compliance

- [ ] **Ethics approval** statement present with committee name and approval number
- [ ] **Informed consent** statement present (for human subjects)
- [ ] **Animal ethics** statement present (for animal research)
- [ ] **Clinical trial registration** number included (if applicable — ICMJE requirement)
- [ ] **PROSPERO registration** number included (for systematic reviews)
- [ ] **Data availability** statement included
- [ ] **Funding** statement present (even if "none")
- [ ] **Conflicts of interest** declared for all authors (even if "none")
- [ ] **AI disclosure** statement prepared (see `ai-disclosure-generator.md`)

## Authorship

- [ ] **All authors** meet ICMJE authorship criteria
- [ ] **No ghost authors** (contributors who should be listed but aren't)
- [ ] **No gift/guest authors** (people listed who didn't contribute substantively)
- [ ] **CRediT roles** assigned to all authors
- [ ] **Corresponding author** identified with complete contact information
- [ ] **ORCID iDs** included for all authors (strongly recommended)
- [ ] **All authors** have reviewed and approved the final manuscript

## Formatting

- [ ] **Word count** within journal limit
- [ ] **Abstract** within word limit and correct structure
- [ ] **Keywords** appropriate in number and vocabulary
- [ ] **Sections** in correct order for journal
- [ ] **Tables** formatted per journal requirements
- [ ] **Figures** at required resolution (typically 300 DPI minimum)
- [ ] **Supplementary materials** properly formatted and referenced
- [ ] **Title page** contains all required information
- [ ] **Running title** present if required

## Reporting Guidelines

- [ ] **CONSORT** checklist completed (for RCTs)
- [ ] **STROBE** checklist completed (for observational studies)
- [ ] **PRISMA** checklist completed (for systematic reviews)
- [ ] **STARD** checklist completed (for diagnostic studies)
- [ ] **CARE** checklist completed (for case reports)
- [ ] **SQUIRE** checklist completed (for quality improvement studies)
- [ ] **EQUATOR Network** guideline checked for study type

## Final Checks

- [ ] **Spelling and grammar** checked (including author names, drug names, abbreviations)
- [ ] **Abbreviations** defined at first use
- [ ] **Units** consistent (SI units preferred for international journals)
- [ ] **Track changes** turned off / clean copy
- [ ] **Comments and annotations** removed
- [ ] **File format** matches journal requirements (.docx, .pdf, LaTeX)
- [ ] **All co-authors** have seen and approved this version
