# Resubmission Verification

## Purpose

Final verification before resubmitting a revised manuscript, ensuring all reviewer points are addressed, all changes are implemented, and the resubmission package is complete.

---

## Verification Checklist

### Reviewer Response Completeness

- [ ] Every editor comment has a response
- [ ] Every Reviewer 1 comment has a response
- [ ] Every Reviewer 2 comment has a response
- [ ] Every Reviewer N comment has a response
- [ ] No comments are marked "TODO" or "TBD"
- [ ] All responses have specific manuscript location references

### Manuscript Consistency

- [ ] Every change promised in the response letter is implemented in the manuscript
- [ ] Page/line numbers in the response letter match the revised manuscript
- [ ] Track changes are present in the tracked version
- [ ] Clean version has no tracked changes or comments
- [ ] Formatting still matches journal requirements after revisions
- [ ] Word count still within limits after revisions

### New Content Verification

- [ ] Any new references added during revision are verified (invoke citation verification)
- [ ] Any new data or analyses are correctly presented
- [ ] New figures/tables are referenced in the text
- [ ] New supplementary materials are properly formatted
- [ ] Author list is unchanged (or changes are disclosed to editor)

### Disclosure Updates

- [ ] AI disclosure updated if AI was used during the revision process
- [ ] COI declarations unchanged (or updates disclosed)
- [ ] Funding statement unchanged (or updates disclosed)
- [ ] Ethics information unchanged

### Resubmission Package

- [ ] Revised manuscript (clean version)
- [ ] Revised manuscript (tracked changes version)
- [ ] Response to reviewers letter
- [ ] Updated supplementary materials (if any)
- [ ] Updated figures (if any)
- [ ] Cover letter for resubmission (brief, referencing MS-ID)
