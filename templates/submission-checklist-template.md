### Manuscript Files

- [ ] Main manuscript file (.docx / .pdf / .tex — per journal format)
- [ ] Title page (separate file if required by journal)
- [ ] Abstract (within word limit: ____ / ____ words)
- [ ] Keywords (correct number: ____ / ____ keywords)
- [ ] All figures as separate high-resolution files (≥300 DPI)
- [ ] All tables (editable format, not images)
- [ ] Supplementary materials (clearly labeled: Table S1, Figure S1, etc.)
- [ ] Cover letter
- [ ] Reporting checklist (CONSORT / STROBE / PRISMA / other: ________)

### Formatting

- [ ] Word count within limit: ____ / ____ words
- [ ] Reference style matches journal requirements (Vancouver / APA / AMA / other)
- [ ] Abstract structure matches requirements (structured / unstructured)
- [ ] Heading levels follow journal style
- [ ] Line spacing correct (double / single / other: ____)
- [ ] Line numbers present (if required)
- [ ] Page numbers present
- [ ] Running title within character limit: ____ / ____ characters
- [ ] Track changes OFF / clean copy
- [ ] All comments and annotations removed

### Content Quality

- [ ] Research question clearly stated
- [ ] Methods sufficiently detailed for replication
- [ ] Results presented completely (including negative findings)
- [ ] Discussion addresses all results
- [ ] Limitations described honestly
- [ ] Conclusions supported by data (no overclaiming)
- [ ] All abbreviations defined at first use

### References

- [ ] All in-text citations have reference list entries
- [ ] All reference list entries are cited in the text
- [ ] Citation verification completed (STOP-02 cleared)
- [ ] No orphan references
- [ ] DOIs included where available
- [ ] No retracted papers cited (Retraction Watch check done)
- [ ] Reference count within journal limit: ____ / ____

### Ethical Compliance

- [ ] Ethics approval statement with committee name and reference number
- [ ] Informed consent statement (for human subjects)
- [ ] Animal ethics statement (for animal research)
- [ ] Clinical trial registration number (ICMJE requirement for trials)
- [ ] PROSPERO registration number (for systematic reviews)

### Declarations

- [ ] Conflicts of interest: declared for ALL authors
- [ ] Funding statement: complete (including "no funding" if applicable)
- [ ] Data availability statement
- [ ] AI disclosure statement (per publisher requirements — STOP-03 cleared)
- [ ] Author contributions (CRediT roles assigned)

### Author Information

- [ ] All author names spelled correctly and consistently
- [ ] All affiliations current and complete
- [ ] ORCID iDs included for all authors (strongly recommended)
- [ ] Corresponding author email and contact information verified
- [ ] ALL authors have reviewed and approved the final manuscript

### Submission Portal

- [ ] Correct article type selected
- [ ] Abstract entered/pasted in submission system
- [ ] Keywords entered in submission system
- [ ] All author metadata entered correctly
- [ ] Suggested reviewers entered (if required): ____ / ____ reviewers
- [ ] Excluded reviewers noted (if any)
- [ ] All required files uploaded
- [ ] Cover letter uploaded/entered

### Final Verification

- [ ] Author names consistent across manuscript, cover letter, and portal
- [ ] Title consistent across all documents
- [ ] Abstract consistent between manuscript and portal
- [ ] Figures/tables referenced in text match uploaded files
- [ ] Supplementary materials referenced in text match uploaded files
- [ ] **STOP-04: Author has reviewed and approved the complete submission package**
